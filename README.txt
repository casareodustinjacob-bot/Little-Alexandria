LITTLE ALEXANDRIA WEBSITE

FILES
- index.html       Home page
- about.html       About Us page
- directory.html   Libraries page
- featured.html    Featured Books and Programs page
- contact.html     Contact and Website Guide page
- styles.css       Shared design for all five pages

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open the website in your browser.
4. Use the navigation links to move between pages.

HOW TO ADD YOUR OWN IMAGES
1. Create a folder named "images" in this website folder.
2. Put your image files inside the images folder.
3. Find an image placeholder comment in an HTML file.
4. Replace the placeholder div with an image tag.

Example:
<img class="page-image" src="images/library-photo.jpg" alt="A library">

Make sure the image filename matches the name in the src attribute.

NOTES
- All five pages use the same styles.css file.
- The library information is sample content. Check details with each library before publishing.
- The contact form is only a visual sample and does not send messages.
